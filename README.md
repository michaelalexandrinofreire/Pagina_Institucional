🚀 Projeto In9ve - Proposta de Interface para Provedor de Internet
Este projeto foi desenvolvido como parte integrante do Estágio Obrigatório em Desenvolvimento Web do curso bacherelado em Sistemas de Informação. O objetivo foi aplicar conceitos de UI/UX, responsividade e performance utilizando tecnologias de ponta no ecossistema JavaScript.

📋 Sobre o Projeto
A In9ve é um provedor de internet focado na região do Cariri e cidades circunvizinhas. O desafio deste projeto foi criar uma Landing Page de alta conversão, focada na clareza dos planos de fibra óptica e na facilidade de contato para verificação de cobertura em cidades do interior.

🛠️ Tecnologias Utilizadas
Framework: Next.js

Linguagem: TypeScript

Estilização: Tailwind CSS

Ícones: Lucide React

🚀 Como Rodar o Projeto
Clone o repositório:

Bash
git clone https://github.com/seu-usuario/in9ve-estagio.git
Instale as dependências:

Bash
npm install
Execute o servidor de desenvolvimento:

Bash
npm run dev
Acesse no navegador:
http://localhost:3000
